# Android 界面设计与实现映射

**设计方向** 深松绿牌桌承载真实牌局，暖白界面承载选游戏、设置和说明。牌面保留用户所选牌组，取消、返回和读档继续由原来的牌局逻辑处理。静态画板按 390 × 844 dp 创建，竖屏列表使用整宽，横屏可并排看牌桌与面板。

Noto Sans SC Regular，SIL OFL 1.1。设计图用同字族导出，应用简中字体来自源码内的静态字重。首屏、玩法选择和设置的概念图由内置 ImageGen 独立生成，存放在 `mood`。结构化可编辑图以 `PySolFC-Android.haoke-ui.json` 为准。

| 画板与状态 | 运行入口与实现 |
| --- | --- |
| 牌桌、移牌、空当接龙、暂停、新牌局提示 | `LMainWindow`、`PysolToolbarTk`、`MyToastButton`、现有 `MfxCanvas` 和游戏引擎 |
| 主菜单、牌局管理、最近玩过、收藏、工具、辅助 | `LMenuDialog`、`LTreeNode`、对应菜单类 |
| 玩法分类、热门展开、当前玩法 | `SelectGameDialog`、`LGameNode`，四种常见玩法优先，其他类别与现有排序保留 |
| 设置目录、触控选择、外观和动效 | `LOptionsMenuGenerator`，同类展开、单选和开关共享组件 |
| 统计入口和当前牌局统计 | `GameMenuDialog`、`SingleGame_StatsDialog`，样例数值仅用于预览 |
| 帮助、操作指南、规则、许可证和关于 | `HelpMenuDialog`、`HTMLViewer`、`PysolAboutDialog` |
| 启动、读取失败、保存提示、获胜和完整图案 | Android 启动画面、`MfxMessageDialog`、`MfxExceptionDialog`、`Toast`、`FullPictureDialog` |

本地工作台从可编辑设计稿可重新导出 `preview/prototype.html`，原型支持展开、切换和返回，使用合成牌局数据。安装器、系统权限和桌面启动器由 Android 绘制。本软件现有 Android 版没有桌面小组件。

游戏界面打开一个新面板时渐显 160 ms，快速离开时取消原面板的渐显；选择无动效后界面直接出现。展开、单选和禁用按钮使用可见的静态反馈。移牌、翻牌和发牌继续运行现有游戏动效以及速度设定，原型使用户可以操作关键转场。

Windows Kivy 的实际运行图放在 `运行截图`。横屏适配和触控仍需在 Android 真机确认。
