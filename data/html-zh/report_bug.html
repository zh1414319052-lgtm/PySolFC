报告错误

在报告错误之前，请验证您是否正在运行最新版本的 PySolFC。另外，请检查 常见问题以及之前在 GitHub 上报告的问题，以确保之前没有报告该错误。

如果您在 PySolFC 中发现错误，最好的报告位置是 GitHub。为此，请在以下位置创建问题 https://github.com/shlomif/PySolFC/issues 尽可能详细地了解正在发生的事情，我们将进行调查。

或者，您可以在 SourceForge 的论坛上报告错误： https://sourceforge.net/p/pysolfc/discussion/ 或通过 SourceForge 的票务系统 https://sourceforge.net/p/pysolfc/_list/tickets。然而，这些检查的频率并不像 GitHub 那样频繁。

增强功能和功能请求

如果您想要请求 PySolFC 的增强功能或新功能，也可以通过在同一位置创建问题来完成。
