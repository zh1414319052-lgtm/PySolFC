安装

PySolFC 是免费开源软件，在 GNU GPL。它将在 Windows、Mac、Linux、Android 等上运行。最简单的运行方法是使用独立的安装程序，该安装程序适用于大多数受支持的操作系统。

窗户

您可以从以下位置下载最新的 Windows 安装程序 来源锻造。安装程序包括应用程序、Python 以及运行 PySolFC 的所有要求。提供基本安装程序和完整安装程序 - 完整安装程序包括应用程序，以及全套卡组和所有附加功能。

Linux

PySolFC 可从 平轮 （包括完整的卡片集集合）。您的 Linux 发行版也可能提供自己的软件包，但请注意，这些软件包可能并不总是完全最新的。此外，您还可以从 SourceForge 下载 tarball。

麦克

您可以从 SourceForge 下载 .DMG 包，然后像任何 Mac 应用程序一样安装它。与 Windows 安装程序一样，提供基本包和完整包。

卡组和其他文件

附加卡组、音乐和设置存储在 〜/.PySolFC/ （或 %APPDATA%\PySolFC\ 在 Windows 上），组织如下：

  • 卡组/ - 卡片组和卡片图像
  • 音乐/ - 背景音乐曲目
  • 瓷砖/ - 桌子瓷砖背景
  • 插件/ - 应用程序插件
  • 保存游戏、选项和统计数据的文件夹

该应用程序的安装目录还包含捆绑的卡组和数据；上面的文件夹是存储每个用户内容和设置的位置。

您可以从 SourceForge 下载其他内容，但如果您下载了完整的 Windows/Mac 软件包或 Flathub 版本，则已经包含完整的内容：

  • 卡组
  • 音乐

更新中

您可以在 PySolFC 网站、在线文档中的新闻页面以及 SourceForge/Flathub/F-Droid 网站上检查新版本。 PySolFC 用户文件夹中的统计信息、选项和用户数据将在更新过程中保留。

从源代码运行

开发人员还可以从源代码运行 PySolFC。您可以克隆 GitHub 存储库 并运行 python3 pysol.py 安装 Python 3.7+、Tkinter 和 pysol 卡 包。有关完整详细信息，请参阅存储库的自述文件。

从命令行运行

许多命令行选项可用于特殊运行选项，即 pysol.py --game="空当接龙"。运行与 --帮助 命令参数以获取有关不同选项的更多详细信息。

故障排除

安装过程中可能会出现以下错误：

  • “没有找到卡组。” - 如上所述安装卡组包。
  • 如果您使用 Linux 发行版中的卡集包，如果从源代码或不同的安装程序运行，它可能与应用程序不一致。卸载该发行版的卡片集软件包并安装来自 SourceForge 的卡片集软件包。
  • 如果您收到缺少卡组类型警告，请更新卡组包。否则某些游戏可能无法正常运行。
  • 另请参阅 常见问题.
