PySol 使用以下开源技术

  • Python 编程语言
  • Tcl/Tk GUI 工具包
  • SDL 简单 DirectMedia 层
  • SDL MPEG 播放器库
  • MikMod 声音库

PySol 是使用以下开源技术创建的

  • Linux操作系统
  • XFree86 X 窗口系统
  • KDE 桌面环境
  • FTE 文本编辑器
  • Inno Setup Win32 安装程序
